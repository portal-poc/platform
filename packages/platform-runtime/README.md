# @portal-poc/platform-runtime

**The React side of the contract**, bundled into every app (host and remotes; not an MF singleton — each app has its
own copy, any version). Hooks that read the platform the app was mounted with, the QueryClient factory, leave guards
and page titles, devtools, stale-build recovery, the standalone harness, and the host-side builders of the contract.

```sh
pnpm add @portal-poc/platform-runtime   # peers: react 19, @tanstack/react-query 5; optional: react-router 8, @azure/msal-browser 5
```

Entries: `@portal-poc/platform-runtime` (everything below), `…/router` (`PlatformLeaveBlocker`, needs react-router),
`…/msal` (`createMsalPlatformAuth`, needs msal-browser), `…/migrations` (for `portal-cli`, not for apps).

## In app code (pages, features)

| Export | Use it to |
|---|---|
| `PlatformProvider` | Wrap your app with the `platform` prop you received (generated entries already do). |
| `usePlatform()`, `usePlatformAuth()`, `usePlatformEnv()`, `usePlatformEvents()`, `usePlatformTelemetry()`, `usePlatformLanguage()` | Read the contract in components. |
| `useLeaveGuard({ when, message?, lock?, allows?, dialog? })` | "Don't leave this page yet": a dirty form (`when: isDirty`), a save in flight (`lock: true`), wizard steps that are not leaving (`allows`), your own dialog (`dialog: 'own'` → render while `state === 'asking'`, answer `leave()` / `stay()`). `release()` before navigating away yourself after saving. Works the same integrated, bridge and standalone. |
| `usePageTitle(title)` | Name the page; the host shows `<title> · <section> · Portal` and restores the section title on unmount. |
| `createPortalQueryClient({ telemetry, config })` | Your app's OWN QueryClient with portal defaults (no retry on 4xx / validation errors, errors to telemetry). A factory — never share an instance. |
| `shouldRetryQuery` | The same retry rule for a custom client. |
| `useClearCacheOnAccountChange(platform, () => queryClient)` | Drop and refetch your cache on logout / account switch (mounted in `RemoteRoot`). |
| `createQueryDevtoolsMount(queryClient)` + `useMarkMounted(platform, name)` | Register your devtools panel in the host's toolbar (lazy chunk, own React root). |
| `PlatformInteractionRequiredError`, `PlatformScopeNotAllowedError`, `isInteractionRequiredError` | Recognise auth failures (a scope outside the registry allowlist is a bug, not a login problem). |

```tsx
const unsaved = useLeaveGuard({ when: form.formState.isDirty, message: 'The task is not saved.' });
const saving = useLeaveGuard({ when: mutation.isPending, lock: true, message: 'Saving…' });
usePageTitle(task.title);
```

Never call React Router's `useBlocker` (lint error from `@portal-poc/presets`): a router has one blocker, and
integrated apps share the host's.

## In entries (`RemoteRoot`, `RemoteBridge`, standalone `main.tsx`) — generated by `portal-cli create remote`

| Export | Use it to |
|---|---|
| `PlatformLeaveBlocker` (`/router`) | The single blocker of a data router you own (bridge / standalone). The host renders its own. |
| `createStandalonePlatform({ appName, env, auth, language?, devtools? })` | A full contract for running the remote alone (`pnpm dev:standalone`): own leave guards with browser dialogs, console telemetry, devtools. |
| `createMockPlatformAuth()`, `DEFAULT_MOCK_ACCOUNTS`, `encodeMockToken` | Mock login for local work and fake BFFs (`mock.<base64 payload>` tokens). |
| `DevtoolsToolbar`, `createDevtoolsRegistry`, `isDevtoolsEnabled` | The devtools drawer in standalone mode (`?devtools=1` on stands). |
| `isStaleBuildError`, `reloadForStaleBuild` | Your own error boundary meets a chunk that a newer deploy removed: reload once (skipped while a leave guard holds the page). |

## In the host

| Export | Use it to |
|---|---|
| `createMsalPlatformAuth(pca)` (`/msal`) | The ONE `PlatformAuth` of the page over one `PublicClientApplication`; interaction only here. |
| `createRemoteAuth(hostAuth, remoteName, allowedScopes)` | Per-remote auth: enforces the remote's scope allowlist, forwards interaction to the host. |
| `createLeaveGuards({ ask, notifyLocked })` | `platform.navigation` of the page: the registry every router's blocker consults. |
| `createPlatformEventBus()` | `platform.events` (EventTarget-based, in-tab). |
| `createConsoleTelemetry()` | Demo telemetry sink; plug Application Insights in production. |
| `installStaleBuildRecovery({ canReload })` | Page-wide reload once when any lazy chunk (host or remote) is gone after a deploy. |
| `isContractVersionSupported`, `isSameReactInstance` | Compatibility checks before mounting a remote. |
| `selectDevtoolsPanel` | Which app's devtools to show (auto-selection rule). |
