# Diagrams

Excalidraw sources (`*.excalidraw`) and their SVG exports (`*.svg`, font embedded) used in the docs:

| Diagram | Shown in |
|---|---|
| `browser` — host, remotes, packages and backends in one page | [platform README](../../README.md#start-here), [overview §1](../overview.md#1-in-the-browser-host-remotes-packages-backends) |
| `packages` — which package each app uses, and how | [overview §2](../overview.md#2-which-package-each-app-uses) |
| `delivery` — from a commit to a stand | [overview §3](../overview.md#3-from-a-commit-to-a-stand) |

To change one: open the `.excalidraw` file at [excalidraw.com](https://excalidraw.com) (Open → the file), edit,
save it back (Save to… → the same file) and export the SVG (Export image → SVG, **Embed scene** off, background on)
over the `.svg` next to it. Keep the numbers on the `browser` arrows in sync with the list in overview §1.
