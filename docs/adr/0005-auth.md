# ADR 0005: Auth: one PCA, interaction only in the host, scope allowlist

## Context

MSAL breaks with two PCAs for one app registration; remotes must not redirect.

## Decision

The host owns one `PlatformAuth` (`createMsalPlatformAuth(pca)` from `@portal/platform-runtime/msal`, mock by default). Each remote gets `createRemoteAuth(base, name, allowedScopes)`: allowlist check (clear error + telemetry), interaction forwarded to the host. Tokens never go into URLs. Teams with their own auth: same tenant → host requests their scopes (default); own app registration → silent-only second PCA; other IdP → OBO in their BFF.

## Consequences

Accepted risk: remotes run in the same origin/realm; the allowlist protects against mistakes, not malice. Minimum: CSP with an allowlist of remote origins (host dev/preview headers).
