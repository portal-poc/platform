# ADR 0014: CLI: template owned by teams, verify is the contract

## Context

Template sync never works across polyrepos.

## Decision

`portal-cli` (commander + @inquirer/prompts): `create remote`, `add <layer> <name>`, `verify`. Generated code belongs to the team; `verify` (in CI) checks name, exposes, singletons and ranges, react-query not singleton, contract version, secrets.

## Consequences

Invest in `verify`, not in template updates. CLI runs TS via Node type stripping in the monorepo; compile before publishing.
