# ADR 0013: FSD 2.1 pages first, Steiger, optional layers

## Context

Teams need a common structure without premature abstractions.

## Decision

`app`, `pages`, `shared` always; `entities`/`features`/`widgets` only when reused. Steiger in lint. `portal-cli create remote` asks which optional layers to create. Example: the bookmark toggle is used by two pages → `features/toggle-bookmark`; query factories in `shared/api`.

## Consequences

Steiger's `repetitive-naming` renamed `task-list` → `list` etc.
